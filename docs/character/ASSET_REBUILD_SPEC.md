## 1. 基准与实测比例

从 V05 三视图自动分割轮廓后量得（总高 H = 594 px，归一化到 1.0）：

| 量 | 值 (×H) | 说明 |
|---|---|---|
| 头宽（含腮毛） | 0.567 | 最宽处 z=0.70 |
| 头高（耳下） | 0.31 | 下巴 0.593 → 颅顶 0.905 |
| 耳尖 | 1.000 | 耳根 0.83 |
| 眼心高 | 0.741 | 眼宽 0.084、双眼心距 0.177 |
| 鼻尖高 | 0.656 | 鼻距身体中心前 0.30 |
| 颈最窄 | 0.444（宽 0.222） | z=0.50 |
| 臀最宽 | 0.700（宽 0.350） | z=0.20 |
| 头深 / 体深 | 0.42 / 0.54 | 侧视 |
| 总宽（含尾） | 0.727 | 正面 |

结论：这是一个**头占近一半高度**的 chibi 比例，眼睛大小约 0.09H。在 76 px 显示下，眼睛直径只有 7 px、颈宽 17 px——任何比这更细的结构都不可见。

| 部件 | 网格 | 材质 |

## 5. 贴图与毛色分布（V05 签收版）

单张 1024² 图集，按 UV 岛分配：
- 底色：银灰（约 #C9C4BC）背侧 → 象牙白（约 #F4EFE7）胸、腹、爪、口鼻。
- 背部：三条纵向"川"字纹，从肩胛到腰，末端变细。
- 侧腰：偏心深斑 + 不规则开放弧（牛眼纹），左右不对称。
- 后脑：不等宽错落弧纹，经后颈接川字纹。
- 尾巴：纯深灰（约 #6E6862），无环纹。
- 项圈遮断处：贴图花纹不得跨过项圈位置。

烘焙流程：Blender 程序化结点 → Cycles bake diffuse/roughness → 图集；AO 另烘一张并入乘法。

## 5b. UV 策略（决定贴图能不能对位）

不用 Smart UV Project：它把岛随机摊开，程序化虎斑无法知道每个岛是背、胸还是腿，贴图必然错位。

改用**按构造生成 UV**：
- 躯干：u = 环向角 / 2π，v = 高度映射到图集躯干区。
- 头：u = 方位角，v = 仰角，映射到头区。
- 四肢与尾：u = 环向角，v = 沿长度。
- 眼睛：独立小岛，放在图集固定角。

这样图集里"哪个像素是背部"在生成时就是确定的，虎斑、白胸、白爪可以直接用 2D 绘制脚本落位，且换姿态不会漂移。

## 6. 绒毛方案（76 px 专用）

真实 groom 毛在 30k 面/4 材质内不可行，采用：
1. **基础体**：平滑着色 + 法线略作毛向扰动（UV 切线方向），提供体积感。
2. **壳层 ×2**：沿法线外扩 0.6% 与 1.2%，alpha 用高频噪声阈值裁剪，形成 1–2 px 的毛边。
3. 壳层与本体共用同一图集与材质，避免额外材质。
4. 关掉 alpha-to-coverage 之外的后处理；桌面常驻要求 30 fps，壳层在 `reduced` 模式下可整层关闭。

验收口径：76 px 下边缘是软的，不出现硬塑料轮廓；3 层叠加不产生明显排序错误。

## 7. 骨骼与动作

沿用 `03_3D_ASSETS_AND_ANIMATION.md` 的命名与 10 个 clip，不新增：
`root, pelvis, spine_01, neck, head, ear_L/R, tail_01..03, front_upper/lower/paw_L/R, hind_upper/lower/paw_L/R, bell`。
坐姿为主，`walk_in_place` 允许原地踏步近似，但必须记录"非最终步态"。

## 8. 验收门槛

1. 正视/侧视/背视轮廓与 V05 的 IoU ≥ 0.90（自动计算，见 `scripts/character/measure.py`；当前 0.891/0.837/0.875）。
   复现：`Blender -b --python scripts/character/build_kitten.py -- --out ../work/out --render`
   然后 `python3 scripts/character/measure.py ../work/out/blockout-front.png --view front`。
2. 76 px 下：双眼、白胸、红领结、尾巴可区分；不依赖放大。
3. 三角 ≤30k、材质 ≤4、draw call ≤8、GLB ≤12 MiB。
4. 10 个 clip 循环无跳帧，脚不穿地。
5. Three.js 桌面实机 30 fps（低功耗 15 fps），隐藏后停帧。
