# 角色贴图与导出检查记录 · coat atlas v1

日期 2026-11-16（Asia/Shanghai），macOS arm64，Blender 5.1.1，Python 3.12 + Pillow 12.3 / numpy 2.3。
执行者：当前主 Agent（DSH），无子 Agent。**作者自测，非独立审核，非视觉签收。**

## 做了什么

1. **按构造生成 UV**（`build_kitten.py` 的 `uv_loft`）：u 取环向索引（正面固定 u=0.5），v 取环序。躯干、四肢、尾、耳全部走这条路径；头部（UV 球）仍用位置投影 `uv_cylindrical`；眼、鼻、口鼻垫、脚趾用平面/单点映射。
2. **图集 1024²**（`scripts/character/atlas_layout.json` 定义分区，`paint_coat.py` 绘制）：躯干 / 头 / 腿 / 尾 / 耳 / 纯白 / 眼 / 鼻 八个区，配色取自签名稿（银灰 `C9C4BC` 系、白 `F6F2EC`、深纹 `68635D`、尾 `6E6862`）。
3. **图案**：胸前白色、背部三条纵向川字纹、侧腰偏心深斑+断弧牛眼、后脑弧纹、尾巴纯深灰。所有以角度为参数的函数都改成 **2π 整数周期**，否则会在背部接缝处出现锯齿。
4. **按材质合并后导出 GLB**：`PULU_fur` / `PULU_eye` / `PULU_red` 三个网格，贴图内嵌。

## 这一轮修掉的 5 个 bug（都会造成肉眼可见的错）

1. UV 接缝处一个面横跨整张图集 → 背部一条白锯齿带。改：按面把 u 钳到 1.0。
2. 在多边形循环里改写了共享的顶点 UV 表 → 全身出现菱形网格。改：按面局部计算。
3. UV 在细分**之后**赋值 → 顶点序号与环/段对不上，贴图彻底错位。改：在 `smooth()` 之前赋值。
4. 尾巴环面没沿路径定向（环是斜椭圆）→ 尾巴边缘出现锯齿。改：环改为平面圆。
5. 渲染曝光用 AgX/强光把颜色洗白 → 误判"贴图没贴上"。改：Standard 视图变换 + 三灯低能量。

## 判定

材质管线打通：程序化建模 → 构造式 UV → 2D 图集 → 3 材质 GLB，全程可 headless 复现。
